# Student Skill Assessment System

## Overview

The Python-based command-line application that is designed to assess and analyze the skills of college students is the Student Skill Assessment System.

The system collects details of students and scores for different skills, calculates the overall performance, identifies the strongest skill and the skill requiring improvement, stores assessment records and generates a detailed report.

## Features

- Student information management
- Skill assessment
- Input validation
- Automatic score calculation
- Percentage calculation
- Performance classification
- Strongest skill identification
- Weakest skill identification
- Student record storage
- Assessment report generation
- Saved-record viewing
- Automated testing

## Skills Assessed

- Programming
- Communication
- Problem Solving
- Technical/Subject Knowledge

Each skill is assessed out of 10.

## Technologies Used

- Python 3
- JSON
- Python `unittest`
- Command-line interface
- Git and GitHub
